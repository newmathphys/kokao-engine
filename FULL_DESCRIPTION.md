# Kokao Engine v1.0 – Gradient Signal Inversion Engine

**Ключевые слова**: PyTorch, метод Косякова, инверсия сигналов, интерпретируемый ИИ, контрфактические объяснения, генетическая оптимизация, модульная архитектура.

---

## 🎯 Идентичность проекта

> **Gradient Signal Inversion Engine on PyTorch**  
> Инвертируйте любой целевой сигнал обратно во входные признаки с помощью дифференцируемой оптимизации (Adam, L1‑регуляризация) через ядро Kokao.

### Основная цель

Реализовать метод **инверсии сигналов** (метод Косякова), при котором вместо прямого обучения весов мы оптимизируем входной вектор `x`, чтобы `signal(x) = target_S`, используя градиентный спуск и регуляризацию. Движок также включает классическое обучение по правилу Косякова, генетическую оптимизацию и модули для работы с мультимодальными данными, графами, квантовыми вычислениями и распределёнными системами.

### Для кого предназначен

| Пользователь       | Задача                                                     |
| ------------------ | ---------------------------------------------------------- |
| **Исследователи**  | Эксперименты с обратной инверсией сигналов, изучение интерпретируемости |
| **ML-инженеры**    | Демонстрационные системы (анализ причинности, контрфактуалы) |
| **Студенты**       | Изучение градиентной оптимизации и метода Косякова          |

### Ключевые преимущества

- **Гибкость** – работает с любыми архитектурами через единый интерфейс `signal()`.
- **Скорость** – GPU-ускорение (CUDA) через PyTorch.
- **Интерпретируемость** – контрфактические объяснения, анализ вкладов факторов.
- **Документированность** – 100% покрытие тестами, подробные примеры, руководства.
- **Типизация** – type hints для всех функций.
- **Простота** – минималистичный API: `core.signal(x)`, `core.train(x, target)`.

## 🧱 Архитектура ядра

### KokaoCoreV9 – центральный вычислительный узел

Ядро хранит нормализованный вектор весов `w` (сумма модулей равна 100) и предоставляет методы:

| Метод | Описание | Типы |
|-------|----------|------|
| `signal(x)` | Вычисляет сигнал `S = wᵀx` | `torch.Tensor → float` |
| `train(x, target)` | Классическое обучение по формуле Косякова (без градиентов) | `torch.Tensor, float → float` (возвращает loss) |
| `train_many(X, target, epochs, lr)` | Градиентное обучение (Adam) на батче | `torch.Tensor, float, int, float → float` |
| `forget(rate)` | Уменьшает веса на `rate` и перенормализует | `float → None` |
| `forget_adaptive(rate, current_s, s_max)` | Забывание с учётом текущего сигнала | – |
| `save(path)` / `load(path)` | Сериализация весов | – |

**Свойства**:
- `w` – тензор весов (нормализован, `sum(|w|) = 100`).
- `device` – CPU или CUDA.
- `history` – история изменений весов (список тензоров).

### Взаимодействие с модулями

| Модуль | Использует | Описание |
|--------|------------|----------|
| **CounterfactualKokao** | `core.signal()` | Генерация минимальных изменений входа для достижения целевого приращения сигнала |
| **KokaoDecoder** | `core.signal()` | Генерация входа, максимизирующего заданный сигнал (градиентный подъём) |
| **EvolveKokao** | `core.signal()`, `core.train()` | Генетическая оптимизация весов |
| **LearnableForget** | `core.forget()`, параметр `alpha` | Дифференцируемая скорость забывания |
| **Остальные модули** (CLIP, SNN, Quantum, Ray и др.) | Работают независимо или через ядро | – |

Все модули спроектированы как независимые расширения, не изменяющие исходный код ядра. Это гарантирует обратную совместимость и лёгкость поддержки.

## 🔢 Математическая основа

### Прямой проход (ядро)

\[
S(\mathbf{x}) = \mathbf{w}^T \mathbf{x}, \quad \text{with } \sum_i |w_i| = 100
\]

Нормализация по сумме модулей обеспечивает:
- **Инвариантность к знаку** – веса могут быть положительными и отрицательными, их «сила» измеряется модулем.
- **Стабилизацию градиентов** – предотвращает «разрыв» векторов.
- **Интерпретируемость** – `S` лежит в диапазоне от 0 до 100 (при положительных входах).

### Инверсная задача

Дан целевой сигнал `target_S`, найти вход `x`, который его даёт:

\[
\mathbf{x}^* = \arg\min_{\mathbf{x}} \big( S(\mathbf{x}) - \text{target\_S} \big)^2 + \lambda \|\mathbf{x} - \mathbf{x}_0\|_1
\]

- Оптимизируется через **Adam** (или L‑BFGS) с autograd.
- Первый член – MSE, второй – L1‑регуляризация для разреженных изменений.

Этот подход используется в модулях **CounterfactualKokao** (минимальное изменение для изменения решения) и **KokaoDecoder** (генерация нового вектора с нуля).

### Обучение ядра

Движок поддерживает два режима обучения:

1. **Классическое обучение по Косякову** (формула (8) из книги):  
   \[
   w_{\text{new}} = w + \eta \cdot (S_{\text{target}} - S) \cdot x
   \]
   Быстрое, без градиентов, используется в `train()`.

2. **Градиентное обучение** (Adam):  
   Используется в `train_many()` для батчей, поддерживает autograd, что необходимо для инверсии.

**Важно**: инверсия (Counterfactual, Decoder) всегда использует градиентный режим.

### Функции потерь

| Loss | Формула | Применение |
|------|---------|------------|
| **MSE** | \((S - \text{target})^2\) | Основная |
| **MAE** | \(\|S - \text{target}\|\) | Робастная альтернатива |
| **L1‑регуляризация** | \(\|\mathbf{x} - \mathbf{x}_0\|_1\) | Поощрение минимальных изменений |

## ⚙️ Установка и быстрый старт

### Установка

```bash
pip install kokao-engine
# или с дополнительными модулями:
pip install kokao-engine[snn,quantum,ray,all]
```

### Пример использования

```python
import torch
from kokao.core import KokaoCoreV9
from kokao.counterfactual import CounterfactualKokao

# 1. Создание ядра
core = KokaoCoreV9(n_features=5)

# 2. Прямой сигнал
x = torch.randn(5)
print("Signal:", core.signal(x))

# 3. Обучение на целевой сигнал (классическое)
loss = core.train(x, target=100.0)

# 4. Контрфактический анализ: найти минимальное изменение для увеличения сигнала на 20
cf = CounterfactualKokao(core)
x_cf = cf.counterfactual(x, target_delta=20.0)
print("Counterfactual signal:", core.signal(x_cf))
```
